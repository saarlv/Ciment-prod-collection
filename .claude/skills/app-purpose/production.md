# Production build

A sub-guide of the `app-purpose` skill, for every app that is not a **demo**: one whose purpose is
production, and one whose purpose was never recorded.

A production app is built the way every app is built today: follow the rest of the platform
guidance (the orchestrator instructions, `plan`, `agentic-apps`, `agent-builder`, `app-artifacts` and the
other skills). This guide adds nothing on top of them yet.
