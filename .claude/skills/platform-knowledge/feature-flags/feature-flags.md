# Feature flags behind platform features

Some features are switched on per account with a feature flag. Wherever a sub-file describes one, it's marked `[flag: <name>]`. This index lists every such flag and what the user sees when it's on.

**The flag name is internal; never show it to the user.** If a flagged feature is missing for them, say it may not be enabled for their account yet and that support can help. When a tool to check flags is available, check the flag for the current account instead of guessing.

Each line: flag → what the user gets when it's on → where it's described.

- `builder-agent-harness` → **Engine** and **Model** rows in Chat settings; the **Claude Code key** card (never on HIPAA accounts) → `building/chat-settings-and-own-key.md`
- `builder-agent-video` → **Videos** switch in Chat settings; with it on, asking Ella for a video of the app gives a narrated, captioned mp4 that plays in the chat and is saved under **User Uploads** → `building/chat-settings-and-own-key.md`
- `ella-down` → an operations pause switch, never a per-account feature: the chat's message box is replaced by **Chat is temporarily unavailable** and nothing sends until it's switched off → `building/troubleshooting.md`
- `app-framework-build` → a public app's fixed-address pages arrive with their content in the page (built with the app), so search engines and link previews read it; nothing to switch on in the app → `app-settings/domain-and-branding.md`
- `app-seo-crawlable-pages` → **Crawlable Pages** card on **Settings → Customization → Search Engine** (public apps): per-page titles and descriptions, redirects, 404s, generated `robots.txt` and `sitemap.xml` → `app-settings/domain-and-branding.md`
- `git-sync` → **Account → GitHub**, app **Git Sync**, branches in the version switcher, and **Settings → Git Sync** in the Blocks mobile app → `app-settings/settings-sections.md`, `building/versions-and-publishing.md`
- `notifications-center` → The **Notifications** bell on the web rail and in each app's rail, the **Notifications** tab and in-app bell in the Blocks mobile app, desktop notifications, the **User** → **Notifications** settings page, and the agent page's **Notify people** setting (app agents' notifications) → `navigation/notifications.md`, `navigation/platform-layout.md`, `navigation/builder-layout.md`, `app-capabilities/agents-and-channels.md`
- `platform-language` → **Language** on **My account** and **My profile**: eleven languages, Hebrew and Arabic reading right to left; off, everyone sees English and **Layout direction** takes its place → `navigation/platform-layout.md`, `account/account-admin.md`
- `academy` → **Academy** in the rail and the **Learn** tab in the Blocks mobile app: lessons with video, audio and text on one page, in English and Hebrew, with progress → `navigation/academy.md`, `navigation/platform-layout.md`, `navigation/mobile-app.md`
- `brain-enabled` → **Brain** in the rail and in the account row's menu inside an app, the **Company data**, **Saved queries** and **Search indexes** groups in an app's Data panel, the **dbt project** in apps, apps searching company data (file folders and tables) by meaning, set up from the chat, and company data added to an app like an integration (the **Company data** card with **Use company data** in the chat, and the **Brain** card on the app's **Settings → Integrations**; adding or removing it needs a role in Brain), and Brain's two levels of access (**Can access** views sources and runs **Sync now** on a company table in an app; **Can manage** or **Can build** also connects, changes and deletes them; **Ask a Brain admin for access** for anyone without a role) → `app-capabilities/brain-company-data.md`, `building/data-world.md`, `navigation/builder-layout.md`
- `rag` → knowledge indexing for agents, and each file's indexing status in **User Uploads** → `building/data-world.md`, `app-capabilities/agents-and-channels.md`
- `kb-view` → **Knowledge Base** folder in Data → `building/data-world.md`
- `data-revert` → **Revert this change** on Data entries in the Activity log (a bulk change shown as one entry, then marked **Reverted**), **View history** in a record's **⋯** menu, and **See this table at an earlier time** / **Restore table to this point** in the data editor → `navigation/builder-layout.md`, `building/data-world.md`, `building/versions-and-publishing.md`
- `data-editor-v2` → the spreadsheet-style table editor in Data: in-place editing, paste from spreadsheets, picking linked records by name, sort, group, an expanded record panel and column summaries → `building/data-world.md`
- `agent-live-turn-stream` → replies keep going after a refresh, workflow and reminder replies stream live in the chat, **Stop** on replies to chat messages (keeps the partial reply; not on workflow or reminder replies), one message at a time per thread → `app-capabilities/agents-and-channels.md`
- `agent-voice-channel` → **Voice** (phone number) channel on agents → `app-capabilities/agents-and-channels.md`
- `agent-whatsapp-channel` → **WhatsApp** channel on agents → `app-capabilities/agents-and-channels.md`
- `per-user-integration-triggers` → integration triggers (e.g. a new Gmail message) that listen on each app user's own connected account and run the workflow as that user → `building/logic-world.md`, `integrations/integrations.md`
- `meeting-notetaker` → **Meeting Notetaker** actions and triggers → `building/logic-world.md`
- `distributed-apps` → **Distribution** type options (template / installation) → `app-settings/settings-sections.md`
- `use-alternate-apps-domain` → App links on `blocks-apps.com` instead of `blocks-app.diy` → `sharing-and-access/share-dialog.md`
- `account-custom-subdomain` → **Account URL** on **Account → My account**: a custom `<name>.blocks.diy` sign-in address instead of `b-<number>.blocks.diy` → `account/account-admin.md`, `navigation/platform-layout.md`
- `session-management` → **User → Sessions**, **Account → Security center → Member sessions** (with the idle timeout and the **Blocks support access** section), sign-in alert emails, and **Where you're signed in** / **Member sessions** in the mobile app's **Settings** → `account/account-admin.md`, `navigation/mobile-app.md`
- `account-ip-allowlist` → **Account → Security center → IP allowlist** opens ("Coming soon" without it): admins limit the whole account (web, mobile, API keys, MCP, apps) to listed IP addresses and ranges → `account/account-admin.md`
- `app-data-access-rules` → **User properties** on each member (Share → Edit access), per-operation row policies (**Create**, **Update**, **Delete**), membership rules ("only my team's rows" through a members table), column write locks → `sharing-and-access/data-permissions.md`
- `app-data-access-rules-ella` (only with `app-data-access-rules`) → Ella setting up data permissions, multi-tenancy and user properties while building, and asking before she opens data up → `sharing-and-access/data-permissions.md`
- `usage-analytics` → the analytics edition of **Account → Usage**: range picker, comparisons with the previous period, a zoomable chart, findings, a breakdown by app, workflow, category, event type, model, member, agent or run with drill-down, a weekday × hour view, every charged event and per-run details, and CSV exports → `billing/credits.md`
